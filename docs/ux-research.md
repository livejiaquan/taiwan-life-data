# 使用者研究：誰會用「台灣生活資料誌」（2026-10）

這份文件用需求分析的角度回答四件事：誰會來、在什麼情境下來、來做哪幾件事、網頁必須滿足哪些非功能需求。目前沒有訪談或流量資料（站上不放追蹤碼），以下 persona 是**依產品定位、分享機制、README 與既有功能推導出的假設**，標成「假設」的地方上線後應以實際回饋修正。

## 1. Persona

| | P1 出門前的上班族 | P2 幫長輩看天氣的子女 | P3 看作品集的工程師／招募者 | P4 串接資料的開發者 |
|---|---|---|---|---|
| 代表人物（假設） | 30 歲、臺南市安南區、騎機車通勤 | 40 歲、住臺北，爸媽住花蓮 | 技術主管、HR、開源貢獻者 | 做 Bot、儀表板、用 Claude 的人 |
| 從哪裡進來 | 手機書籤、主畫面捷徑 | LINE 收到的分享連結 | GitHub README 的線上版連結 | README、`docs/API.md`、MCP 說明 |
| 主要裝置 | 手機（直式、單手） | 手機為主 | **桌面**為主 | 桌面 |
| 停留時間 | 5–15 秒 | 30 秒–2 分鐘 | 1–3 分鐘 | 數分鐘，會點進 `/status` |
| 最在意 | 今天要不要帶傘、防曬、口罩 | 有沒有警特報、能不能放心讓長輩出門 | 做得精不精緻、資料處理嚴不嚴謹 | 資料多新、格式穩不穩、壞掉時怎麼呈現 |
| 會被什麼勸退 | 要捲很久才看到結論 | 字太小、術語太多、不知道資料是不是舊的 | 樣板感、手機跑版、深色模式壞掉 | 看不出資料時間、狀態不一致 |

## 2. 使用情境

1. **早上 7:40 出門前**（P1）：單手拿手機打開書籤，頁面記得上次的鄉鎮。期待 5 秒內知道「今天正常出門」或「留意紫外線」。網路可能是 4G 且訊號普通。
2. **颱風前一晚**（P2）：在 LINE 家族群組收到連結，點開是爸媽所在的花蓮縣某鄉鎮。要一眼看到有沒有警特報、資料是不是最新的，再按「傳到 LINE」回覆家人。
3. **審閱作品集**（P3）：在桌面瀏覽器從 GitHub 點進來，1440 px 寬，可能是深色系統主題。會切換縣市、縮放視窗、看看深色模式、點到「資料狀態」頁。
4. **資料壞掉的時候**（P1–P4 都會遇到）：收集排程中斷、官方 API 讀不到。頁面必須清楚說「這項不下結論」，而不是顯示舊的「正常」。

## 3. 前三項任務

| # | 任務 | 成功標準 | 設計回應 |
|---|---|---|---|
| T1 | 看今天出門要注意什麼 | 首屏、不捲動、5 秒內讀到結論與哪幾項有狀況 | 今日重點卡：一句大字總結＋五格指數列（圖示＋等級詞） |
| T2 | 確認資料可不可信 | 每項都看得到資料時間與新舊；過舊時不會被誤讀成正常 | 卡片底部固定的資料時間列；「過舊」用斜紋＋虛線，總結卡寫「N 項不下結論」 |
| T3 | 換地點／分享給家人 | 兩次點選換到任一鄉鎮；分享內容附資料時間 | 頂部兩個大下拉選單（≥48 px）；網址帶地點；LINE／文字／圖卡分享 |

次要任務：看電網碳強度與水庫（`/today/`）、查資料來源狀態與事故（`/status/`）、找 API 與 MCP。

## 4. 裝置評估

- **台灣整體網路流量**：StatCounter 2026 年 5–8 月的快照，手機約 50–53%、桌面約 46–48%、平板約 3%（不同頁面的數字略有出入，9 月一頁標示異常的快照為手機 60%）。<https://gs.statcounter.com/platform-market-share/desktop-mobile-tablet/taiwan/2025>
- **本站的情境偏向**：T1、T3 的分享路徑（LINE）幾乎都在手機上；但這個 repo 也是作品集，P3 幾乎都用桌面打開。
- **推估**：首頁「出門前」手機約 70%、桌面約 30%；`/status` 與 API 文件反過來，桌面約 70%（假設，依 persona 推導）。

**結論：兩邊都重要，兩邊都要做好看。** 手機是 T1 的主力，要精緻到單手 5 秒內看懂；桌面是第一印象（作品集），不能只是把手機版拉寬。所以：手機單欄、指數列五格並排；桌面兩欄細節卡、指數列橫向、頂端導覽固定。

## 5. 非功能需求

| 類別 | 需求 | 驗收方式 |
|---|---|---|
| 正確性 | 過舊或讀不到一律不下結論；網站與 MCP 結論相同 | 既有單元測試（`packages/assess`）；這次改版不動判讀邏輯 |
| 效能 | 4G 手機首次繪製不需 JS（預先產生 HTML）；Lighthouse performance ≥ 90 | Lighthouse mobile／desktop |
| 版面穩定 | 讀取中→載入完成不推動下方內容；CLS ≤ 0.1 | Lighthouse CLS；讀取中預留高度 |
| 無障礙 | WCAG 2.1 AA 對比；觸控目標 ≥ 44 px；顏色不是唯一訊號；鍵盤可操作、焦點可見；`prefers-reduced-motion` | 對比計算腳本、Lighthouse accessibility ≥ 90、手動檢查 |
| 深淺色 | 跟隨系統，也可手動切換；切換不閃爍 | 兩種主題截圖 |
| 隱私 | 無追蹤碼、無第三方字型或腳本；地點只存在網址與本機 localStorage | 建置產物掃描（既有 `build:public`） |
| 可維護 | 設計 token 集中在 `styles.css` 開頭；三頁共用 `Shell.tsx` | 程式碼審查 |
