# 電網碳強度：計算方法與係數出處

「現在每用一度電，大約排放多少公克二氧化碳當量（gCO₂e/kWh）」——本站 `/today/` 頁與 `data/power.json` 的 `intensity`。

程式：`packages/collectors/src/carbon.ts`（係數與公式）、`packages/collectors/src/power.ts`（台電資料解析）。測試：`packages/collectors/test/today.test.ts`（含一筆用台電實際檔案手算核對的案例）。

## 2. 公式

```
碳強度 = Σ（能源別 i 的淨發電 MW × 係數 i） ÷ Σ（能源別 i 的淨發電 MW）
```

- **只算一次發電**：儲能放電（電池、抽蓄）與儲能充電負載**不計入分子也不計入分母**。儲能放出的電是之前發的，當時已經算過；若把它當 0 排放計入，會低估碳強度。
- 負值（機組自用大於發電）以 0 計。
- 機組類型去掉 HTML 標籤後歸類（同 taiwan-power-dashboard 的對照）：

| 台電「機組類型」 | 本站類別 |
|---|---|
| 燃煤、民營電廠-燃煤 | coal |
| 燃氣、民營電廠-燃氣 | gas |
| 燃料油、燃油、輕油、柴油 | oil |
| 汽電共生 | cogeneration |
| 核能 | nuclear |
| 水力 | hydro |
| 風力 | wind |
| 太陽能 | solar |
| 其它再生能源、地熱、生質 | other-renewable |
| 儲能、抽蓄 | storage（不計） |
| 儲能負載 | storage-load（不計） |

**取值來源**：以上數字照抄 Electricity Maps 開源設定檔 [`config/defaults.yaml`](https://github.com/electricitymaps/electricitymaps-contrib/blob/d9a920fb7c357fefd8616adddcab3c17b0aa26ff/config/defaults.yaml)（commit `d9a920f`，2026-04-28；2026-10-16 讀取），該檔逐項註明上表的原始出處。「汽電共生＝未知火力」也跟隨 Electricity Maps 的台電解析器（`electricitymap/contrib/parsers/TAIPOWER.py` 把 `COGEN` 歸為 `unknown`）。只引用係數數值，沒有使用其程式碼。係數版本記在每筆資料的 `factorsVersion`。

**為什麼主要指標用生命週期**：可以和 Electricity Maps 等國際服務直接比較（競品報告 §8.2 的「與 Electricity Maps 的差距」），而且風、光、水在生命週期下不是 0，比較誠實。直接排放一併提供，方便和政府公告的係數對照。

## 5. 誤差與限制

1. **係數是全球中位數**，不是台灣各電廠的實際熱效率；燃氣複循環與舊式燃氣機組差異可達數成。
2. **汽電共生**實際燃料以燃煤、燃氣為主但比例未公開，用「未知火力」700／575 是保守估計。
3. **屋頂型自發自用太陽能**不在台電資料裡（只看得到併網後的發電），白天實際碳強度可能比本站顯示的再低一些。
4. **瞬間值 vs 年平均**：官方係數以年售電量為分母、扣除線損，與本站「這 10 分鐘發電端」的定義不同，不應直接比大小。
5. **新鮮度**：台電每 10 分鐘更新，但本站收集排程目前不準（DECISIONS D2）；資料超過 90 分鐘就不顯示目前碳強度，而不是顯示舊值。
6. 台灣電網無跨國聯網，沒有進口電力要處理。

## 6. 綠電時段

- 由本站**歷史存檔**中的碳強度樣本計算：最近 14 天，依台北時間每小時取平均，找平均最低的連續 3 小時（可跨午夜）。
- 至少 48 筆樣本、18 個小時有資料才會給出時段；否則顯示「樣本不足」與目前筆數。
- 這是**過去的規律，不是預報**。
- **為什麼不用台電的歷史檔 d006010**：它有逐 10 分鐘的機組資料（2026-03-01～05-31，約 196 MB），但實際解析後只含台電自有機組——例如 2026-04-15 12:00 太陽能只有 84 MW、沒有民營電廠與外購的風、光。用它算出的逐時碳強度幾乎是平的（617–623 g），會誤導。詳見 DECISIONS D20。
